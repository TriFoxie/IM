# ItM Coursework
*Formative coursework for the Introduction to Multimedia module.*
## Specification
Create a set of CSS managed web pages to the following specification and adhering to HCI and design guidelines.  
Development should contain the following 5 pages:
1. Home page
2. A Video page
3. A Hobbies/Activities Page
4. A Coursework page
5. A Clock animation using JavaScript
